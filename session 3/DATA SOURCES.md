# Data Sources & Setup Guide

This file explains where to download every dataset needed to run the pipeline.
None of the raw data files are stored in this repo (too large for GitHub).

---

## Folder Structure Expected

After downloading everything, your `session 3/` folder should look like this:

```
session 3/
├── data/
│   ├── raw/                         ← 8 air quality CSVs go here
│   ├── processed/                   ← generated by clean_multistation.py
│   └── output/                      ← generated by spatial_features_pipeline.py
├── scripts/
│   ├── clean_multistation.py
│   ├── spatial_features_pipeline.py
│   └── clean_krakow_dataset.py
├── docs/
├── reports/
├── CLMS_UA_LCU_...KRAKOW....fgb    ← Urban Atlas file goes here (root)
└── DATA_SOURCES.md                  ← this file
```

## Dataset 1 — Air Quality CSVs (8 stations)

**Source:** AQICN (Air Quality Index China — covers global stations)
**URL:** https://aqicn.org/city/poland/malopolska/krakow-zloty-rog/

**How to download:**
1. Go to https://aqicn.org
2. Search each station name below
3. On each station page, scroll down and download historical data as CSV
4. Save each file in `data/raw/`

**Stations to download:**

| Station | AQICN URL |
|---------|-----------|
| Nowa Huta | https://aqicn.org/city/poland/malopolska/krakow-nowa-huta/ |
| Kurdwanow | https://aqicn.org/city/poland/malopolska/krakow-kurdwanow/ |
| Zloty Rog | https://aqicn.org/city/poland/malopolska/krakow-zloty-rog/ |
| Os. Piastow | https://aqicn.org/city/poland/malopolska/krakow-os.-piastow/ |
| Os. Wadow | https://aqicn.org/city/poland/malopolska/krakow-os.-wadow/ |
| Ul. Dietla | https://aqicn.org/city/poland/malopolska/krakow-ul.-dietla/ |
| Aleja Krasinskiego | https://aqicn.org/city/poland/malopolska/krakow-aleja-krasinskiego/ |

**Note:** Ul. Telimeny was excluded — data only available up to May 2018,
outside the project scope (2019-2024).

**Expected filename format:**
```
nowa-huta, kraków, małopolska-air-quality.csv
kraków,-ul. złoty róg, małopolska-air-quality.csv
...
```

## Dataset 2 — CLMS Urban Atlas (Land Use)

**Source:** Copernicus Land Monitoring Service
**URL:** https://land.copernicus.eu/local/urban-atlas

**How to download:**
1. Go to https://land.copernicus.eu/local/urban-atlas
2. Click "Urban Atlas 2018" (or latest available)
3. Search for **Krakow / Kraków / PL003L2**
4. Download the **FlatGeobuf (.fgb)** format
5. Save the file in the **root** of `session 3/` (next to the scripts folder)

**Expected filename:**
```
CLMS_UA_LCU_S2021_V025ha_PL003L2_KRAKOW_03035_V01_R00_20241025.fgb
```

**File size:** ~150MB — this is why it's excluded from GitHub.

**Alternative:** If the exact file is unavailable, download the GeoPackage (.gpkg)
and update `FGB_PATH` in `scripts/spatial_features_pipeline.py` accordingly.

## How to Run the Full Pipeline

Once all files are downloaded, run these commands in order:

```powershell
cd "C:\Users\...\session 3"

# Step 1: Clean and combine the 8 station CSVs
python scripts/clean_multistation.py
# Output: data/processed/krakow_multistation_CLEANED.csv

# Step 2: Extract spatial features + merge
python scripts/spatial_features_pipeline.py
# Output: data/output/krakow_final_dataset.csv  ← USE THIS FOR MODELING

# Optional: OSM features require internet access (may be blocked on some networks)
# If OSM fails, set FETCH_OSM = False in spatial_features_pipeline.py
# Land use features alone are sufficient for the model
```

**Total runtime:** ~5-10 minutes (longer if OSM is enabled)

```powershell
conda install -c conda-forge geopandas osmnx
```

## Notes

- **COVID period excluded:** 2020-03-15 to 2020-05-31 (abnormal pollution levels)
- **Date range:** 2019-2024 only (project scope per problem-brief-v2.md)
- **OSM features:** Require internet access to overpass-api.de or mirrors.
  If blocked by your network, run from home or use a mobile hotspot.
- **Target variable:** PM2.5 (µg/m³), daily mean
- **Validation target:** R² ≥ 0.40 (leave-one-station-out cross-validation)
